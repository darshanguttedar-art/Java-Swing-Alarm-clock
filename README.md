# ⏰ Java Swing Alarm Clock

A desktop alarm clock application developed using Java Swing.

## ✨ Features
- Live digital clock
- Multiple alarms
- Add and delete alarms
- Custom WAV audio playback
- Stop alarm functionality
- 5-minute snooze
- Dark-themed graphical interface

## 🛠️ Technologies Used
- Java
- Java Swing
- Java Sound API
- Java Time API
- Collections Framework

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Add your own WAV audio file.
4. Update the audio file path in AlarmGUI.java.
5. Compile and run:

```bash
javac AlarmGUI.java
java AlarmGUI
```
